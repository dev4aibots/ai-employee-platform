    What is and is not happening here

    • Real. The schema, the row level security policies, the privilege guard trigger and the seed data are byte-for-byte the files in db/. The queries run as the authenticated Postgres role with the tenant's id set in request.jwt.claim.sub, which is how Supabase passes identity.
    • Real. Denials are PostgreSQL errors and empty result sets, not UI theatre. If a policy were removed, these scenarios would succeed and say so.
    • Not here. The credential vault, HMAC verification, retry policy and audit ledger are covered by the test suite and npm run demo in the repository. They are pure Node modules and have no meaning in a browser tab.
    • Not here. No network calls, no analytics, no cookies. Close the tab and the database is gone.
